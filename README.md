# User Manager

Консольное приложение для управления списком пользователей.

## Функциональность
- Добавление пользователя (имя, возраст, email)
- Просмотр всех пользователей
- Сортировка по имени и возрасту
- Поиск по имени
- Удаление по email
- Сохранение и загрузка из файла (CSV)

## Технологии
- Java 17
- Collections, Stream API, Optional
- I/O (ObjectOutputStream / ObjectInputStream)
- Сериализация (Serializable)

## Запуск
1. Склонировать репозиторий
2. Открыть в IntelliJ IDEA
3. Запустить Main.java
